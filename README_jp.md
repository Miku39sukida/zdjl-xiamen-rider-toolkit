## 🚀 デュアルデバイス設定手順
1. **事前準備**：`merchant_alias.json`をスマホとタブレットのストレージルートに配置し、スクリプトが設定を読み込めるようにする
2. **タブレット**：Auto.jsを開く → 「自动获取取送地址.zjs」をインポート → スクリプトを実行後、注文ページに切り替え（餓了么/美団/UU対応）
3. **スマホ**：
   - Pydroid/Termuxを開く → `config_webui.py`のディレクトリに移動し、実行：`pip install -r requirements.txt`（初回のみ）
   - 実行：`python config_webui.py`で設定サービスを起動
   - ブラウザで `スマホIP:5000` にアクセス → 設定の読み込み成功を確認（廈門ローカル住所プレフィックスが表示されればOK）
   - Auto.jsを開く → 「个人跑单专用_竖屏.zjs」を実行 → タブレットから抽出した住所を自動受信し、美団ナビを起動

## ⚙️ 設定説明
- 設定ファイルはストレージルートに配置（ネストされたフォルダ不可）、そうでないとスクリプトが読み込めません
- テキストエディタで直接`merchant_alias.json`を開き、廈門店舗別名・住所ルールをカスタマイズ可能
- `config_webui.py`はWebインターフェースを提供し、設定ファイルのCRUD操作（店舗別名、住所正規表現ルール等）を行えます。JSONの手動編集は不要

## 📌 対応プラットフォーム
- **住所抽出**：餓了么クラウドソーシング/UUランニング/美団特別配達に対応
- **ナビゲーション**：**美団マップ**を統一呼び出し（配達最適化ルート、迂回減少）

## 🗺️ 美団マップ進入チュートリアル

### 方法1：チャンネルゾーン進入
美団ホームページで、微信のように下にスワイプしてチャンネルゾーンに入り、「地图找店」（マップ店舗検索）をタップ

### 方法2：検索ボックス進入
美団ホームページで検索ボックスをタップし、「地图找店」（マップ店舗検索）と入力して直接進入

### 小美内蔵美団マップ進入方法
会話中で任意のナビゲーション目的地を話すと、AIがマップを呼び出し、タップして進入すればどこでもナビゲーション可能

## ❓ クイックスタートFAQ
1. **スクリプトが反応しない？**
   - Auto.jsで「フローティングウィンドウ+アクセシビリティ権限」が有効か確認（スクリプト動作に必須）
   - 注文ページが縦向きモードか確認（スクリプトは縦向きインターフェース対応）

2. **設定ファイルが読めない？**
   - `merchant_alias.json`がストレージルートにあるか確認（「内部ストレージ」などのサブフォルダではなく、「マイフォン」ルートに直接配置）
   - Auto.jsを再起動してからスクリプトを再実行

3. **Pythonサービスが起動しない？**
   - まず`pip install -r requirements.txt`を実行して依存関係をインストール
   - スマホで「データ制限」が有効でないか確認（一部のスマホはローカルサービスのネットワークリクエストをブロック）

4. **住所抽出が不正確？**
   - `merchant_alias.json`を開き、対応する店舗別名を追加（例：「XXコンビニ」→「XXスーパー」）
   - Web設定ページで認識しきい値を上げる（デフォルト0.8、より高精度の場合は0.9に調整可能）

## 🤝 貢献募集

設定ファイルの更新を手伝ってください。廈門ローカル店舗別名と住所認識ルールの改善にご協力ください！

### 貢献方法

1. **設定環境を構築**：上記「🚀 デュアルデバイス設定手順」のスマホ設定手順を参照（`config_webui.py`を使用して設定サービスを起動）

2. **設定ファイルを編集**：ブラウザで`localhost:5000`または`127.0.0.1:5000`にアクセスし、Webインターフェースで設定ファイルを視覚的にCRUD操作

3. **更新を提出**：編集完了後、更新された`merchant_alias.json`をPRまたはIssueで提出、貢献者はプロジェクト謝辞に記載されます

### 設定説明
- **店舗別名**：一般的な店舗名のバリエーションを追加して認識精度を向上（例：「XXコンビニ」→「XXスーパー」）
- **住所正規表現**：キャプチャグループ（`$1`、`$2`など）をサポートし、複雑な住所形式を正確に処理（例：「后浦社区-36」）
- **設定優先順位**：Web設定はローカルJSONを上書き、Webでテストしてからファイルに同期することを推奨

設定ファイルの更新は全ユーザーに利益をもたらします。すべての貢献者に感謝します！🎉
