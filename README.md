# zdjl-xiamen-rider-toolkit
厦门骑手跑单效率工具包（自动精灵双端脚本）
手机+平板双端联动，地址提取+自动导航一步到位

## 📦 包含文件
| 文件名/类型         | 作用                     | 运行设备 | 存放路径                |
|---------------------|--------------------------|----------|-------------------------|
| README.md           | 使用说明文档             | 通用     | -                       |
| config_webui.py     | 手机Web配置服务核心文件  | 手机     | 任意目录（建议存文档夹）|
| merchant_alias.json | 厦门商家别名配置（适配美团POI） | 通用     | **手机/平板 storage根目录** |
| requirements.txt    | Python依赖清单           | 手机     | 与`config_webui.py`同目录 |
| 自动获取取送地址.zjs | 自动抓取商家/顾客地址    | 平板     | 自动精灵脚本目录        |
| 个人跑单专用_竖屏.zjs| 接收地址后启动美团导航   | 手机     | 自动精灵脚本目录        |

## 🚀 双端联动步骤
1. **前置准备**：将`merchant_alias.json`放到手机和平板的 storage 根目录，确保脚本能读取配置
2. **平板端**：打开自动精灵 → 导入「自动获取取送地址.zjs」→ 运行脚本后切换到订单页面（饿了么/美团/UU都支持）
3. **手机端**：
   - 打开Pydroid/Termux → 进入`config_webui.py`存放目录，执行：`pip install -r requirements.txt`（仅首次运行）
   - 执行：`python config_webui.py` 启动配置服务
   - 浏览器访问 `手机IP:5000` → 验证配置加载成功（显示厦门本地地址前缀即生效）
   - 打开自动精灵 → 运行「个人跑单专用_竖屏.zjs」→ 自动接收平板提取的地址，启动美团导航

## ⚙️ 配置说明
- 配置文件必须放 storage 根目录（无需嵌套文件夹），否则脚本无法读取
- 可直接用记事本打开`merchant_alias.json`，自定义厦门商家别名、地址规则
- `config_webui.py` 提供 Web 界面用于配置文件的增删改查（商家别名、地址正则规则等），无需手动编辑 JSON

## ❓ 快速上手FAQ
1. **脚本运行没反应？**
   - 检查自动精灵是否开启“悬浮窗+无障碍权限”（这两个是脚本运行的必要权限）
   - 确认订单页面处于竖屏状态（脚本适配竖屏界面）

2. **配置文件读不到？**
   - 检查`merchant_alias.json`是否放在 storage 根目录（不是“内部存储”的子文件夹，比如直接放在“我的手机”根目录）
   - 重启自动精灵后再运行脚本

3. **Python服务启动失败？**
   - 先执行`pip install -r requirements.txt`安装依赖
   - 确保手机没开“流量限制”（部分手机会拦截本地服务的网络请求）

4. **地址提取不准确？**
   - 打开`merchant_alias.json`补充对应商家的别名（比如"XX便利店"补充"XX超市"）
   - 在网页配置页提高识别阈值（默认0.8，可调整到0.9增强精准度）

## 🤝 贡献招募

欢迎帮忙更新配置文件，共同完善厦门本地商家别名和地址识别规则！

### 配置文件编辑流程

1. **下载配置文件**
   - 下载`merchant_alias.json`到手机 **storage 根目录**
   - 下载`config_webui.py`和`requirements.txt`到任意目录（建议存文档夹）

2. **搭建本地配置环境（Termux）**
   ```bash
   # 安装依赖（仅首次运行）
   pip install -r requirements.txt
   
   # 启动配置服务（config_webui.py已设置绝对目录）
   # 用于配置文件的增删改查，支持商家别名、地址正则规则等
   python config_webui.py
   ```

3. **访问配置界面**
   - 浏览器打开 `localhost:5000` 或 `127.0.0.1:5000`
   - 可视化增删改查配置文件，实时预览效果

4. **提交更新**
   - 编辑完成后，将更新后的`merchant_alias.json`提交 PR 或 Issue
   - 贡献者将标注在项目致谢中

### 配置说明
- **商家别名**：添加常用商家名称变体，提升识别准确率（如"XX便利店"→"XX超市"）
- **地址正则**：支持捕获组（`$1`, `$2`等），精确处理复杂地址格式（如"后浦社区-36"）
- **配置优先级**：网页配置会覆盖本地JSON，建议先用网页测试再同步到文件

配置文件更新能让所有使用者受益，感谢每一位贡献者！🎉
