# zdjl-xiamen-rider-toolkit
厦门骑手跑单效率工具包（自动精灵双端脚本）
手机+平板双端联动，地址提取+自动导航一步到位

## 📦 包含文件
| 文件名/类型         | 作用                     | 运行设备 | 存放路径                |
|---------------------|--------------------------|----------|-------------------------|
| 自动导航脚本.js     | 接收地址后启动美团导航   | 手机     | 自动精灵脚本目录        |
| 地址提取脚本.js     | 自动抓取商家/顾客地址    | 平板     | 自动精灵脚本目录        |
| merchant_alias.json | 厦门商家别名配置（适配美团POI） | 通用     | **手机/平板 storage根目录** |
| run_server.py       | 手机本地Web配置服务      | 手机     | 任意目录（建议存文档夹）|

## 🚀 双端联动步骤
1. **前置准备**：将`merchant_alias.json`放到手机和平板的 storage 根目录，确保脚本能读取配置
2. **平板端**：打开自动精灵 → 导入「地址提取脚本.js」→ 运行脚本后切换到订单页面（饿了么/美团/UU都支持）
3. **手机端**：
   - 打开Pydroid/Termux → 进入`run_server.py`存放目录，执行命令：`python run_server.py`
   - 浏览器访问 `手机IP:8080` → 验证配置加载成功（显示厦门本地地址前缀即生效）
   - 打开自动精灵 → 运行「自动导航脚本.js」→ 自动接收平板提取的地址，启动美团导航

## ⚙️ 配置说明
- 配置文件必须放 storage 根目录（无需嵌套文件夹），否则脚本无法读取
- 可直接用记事本打开`merchant_alias.json`，自定义厦门商家别名、地址规则
- 网页配置页（`手机IP:8080`）支持可视化调整识别阈值，无需手动改JSON

## 📌 适配平台
支持蜂鸟众包/UU跑腿/美团专送，导航统一调用美团地图（配送优化路线，少绕路）
